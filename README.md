# PS4 14.00 Research

Open research on PS4 firmware 14.00 security: a **proven, reproducible
userland exploit chain** for the console's web browser, plus a measured map
of the kernel attack surface that remains — so the community can pick up the
hunt for the one missing link: a kernel primitive.

**Current state in one line:** userland is done (entry → arbitrary R/W →
base leak → verified ROP → arbitrary syscalls, 15+ full boots on console);
the kernel side is systematically mapped, with the public leads that are
dead on 14.00 proven dead, and the live leads ranked and documented.
See **[STATUS.md](STATUS.md)** for the full declaration.

## Repository map

```
                        dump-libkernel.md (the dump recipe),
                        extract-stubs.py, extract-gadgets.py.

                        a console: selftest-repo.js.

```

## Quick start

1. PC with Python 3 on the same LAN as your PS4 (firmware 14.00, stock,
   browser usable).
2. `tools/host/start.bat` (Windows) or `python tools/host/server.py`
   (any OS) — it prints the URL to open on the console.
3. On the PS4 browser, open the printed URL, pick **POC**, and watch the
   verdict markers (also logged on the PC by the server).
4. Full walkthrough, expected markers, and the operating rules:
   **[REPRODUCE.md](REPRODUCE.md)**.

## What this is for

Everything here is measured or byte-verified, and every claim links to the
tool that produced it. Two things make this repo useful to other
researchers:

- **The negative results are first-class.** Each dead lead (the scene's aio
  kernel exploit, ipmimgr 622, named IPC, dmem/aout, the loader TOCTOU, …)
  is documented with the exact evidence that killed it — so nobody burns
  weeks re-opening doors Sony already closed on 14.00.
  See `docs/06-negative-results.md`.
- **The live leads are ranked and tooled.** The dipsw ioctl window, the
  other visible device nodes, the `/system_tmp` sockets, the bnet
  write-UAF, and the Remote Play surface each have a write-up, a status
  (OPEN / CLOSED / UNTESTED) and a suggested next probe.
  See `docs/07-next-leads.md`.
